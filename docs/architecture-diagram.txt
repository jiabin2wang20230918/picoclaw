Tool Sources
------------
- filesystem tools
- exec / edit / append
- web search + fetch
- browser/CDP tools
- message tool
- cron tool
- spawn/subagent tools
- skill discovery/install
- hardware tools


Gateway Integrations Around The Loop
------------------------------------
- channels manager
- cron service
- heartbeat service
- device event service
- voice transcription
- health server


Important Notes
---------------
- `AgentLoop` is the actual default runtime center.
- Helper abstractions under `pkg/agent/orchestrator`, `permissions`, `execution`,
  `router`, and `supervisor` are not the main production code path.
- There is no active per-tool permission enforcement layer in the default loop.
