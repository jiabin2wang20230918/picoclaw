AgentLoop Core Components Integration:

┌─────────────────────────────────────────────────────────────────────────────┐
│                   AGENTLOOP CORE PROCESS FLOW                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. Message Reception:                                                     │
│    MessageBus → AgentLoop → processMessage()                              │
│                                                                           │
│ 2. Message Routing:                                                       │
│    processMessage() → RouterComponent → determineAgent()                  │
│                                                                           │
│ 3. Context Building:                                                      │
│    Agent determined → ContextBuilder → BuildContext()                     │
│    Includes adaptive compression when needed                              │
│                                                                           │
│ 4. LLM Orchestration:                                                     │
│    Context ready → LLMOrchestrator → runLLMIteration()                    │
│    Handles tool loops and iterations                                      │
│                                                                           │
│ 5. Tool Execution:                                                        │
│    Tool calls detected → ToolExecutor → ExecuteWithContext()              │
│    Includes permission checking via ToolGuard                             │
│                                                                           │
│ 6. State Management:                                                      │
│    Updates → SessionManager & MemoryManager                               │
│    Persists conversation history and memory                               │
│                                                                           │
│ 7. Response Generation:                                                   │
│    Final content → publish to MessageBus → outbound messages              │
└─────────────────────────────────────────────────────────────────────────────┘

Key Interfaces (pkg/agent/interfaces/interfaces.go):
- MessageRouter: Routes messages to appropriate agents
- ContextBuilder: Builds message context for LLM processing
- LLMOrchestrator: Manages LLM interactions and tool loops
- ToolExecutor: Executes tools and manages results
- SessionManager: Handles conversation history and state
- MemoryManager: Handles memory persistence
- AgentSupervisor: Coordinates agent lifecycle and orchestration

Data Flow (Core Loop):
Inbound Message → AgentLoop → Router → ContextBuilder → LLM Orchestrator →
Tool Executor → Session/Memory Managers → Outbound Response

Permissions Enforcement:
All tool executions pass through ToolGuard which checks policies before allowing execution based on agent ID and channel.
