# QuantClaw

QuantClaw 是一个轻量级 Go agent runtime，用于在终端、长期运行的 gateway 或聊天通道后面运行个人 AI 助手。

当前中文 README 需要按新的 QuantClaw 定位重新翻译。为了避免继续保留过期宣传内容和失效图片，本文件暂时只保留入口说明。

请以英文主文档为准：[README.md](README.md)。

快速开始：

```bash
git clone https://github.com/sipeed/quantclaw.git
cd quantclaw
make build
./build/quantclaw onboard
./build/quantclaw agent -m "Summarize this repository"
```
